# Hansung AI Assistant — 프로젝트 상세

## 프로젝트 개요

한성대학교 학생이 공지사항, 수강신청, 학사일정, 입학 정보 등을 자연어로 질문하고 답변받을 수 있는 AI 캠퍼스 챗봇입니다. 학교 정보가 여러 사이트와 문서에 흩어져 있어 필요한 내용을 찾기 어려운 문제를 줄이는 것을 목표로 했습니다.

## 해결하려 한 문제

- 공지사항과 학사 정보가 여러 웹사이트에 분산되어 있음
- 학생이 필요한 정보를 찾으려면 여러 페이지를 직접 확인해야 함
- 학교 내부 문서와 최신 웹 정보를 함께 활용할 수 있는 안내 창구가 부족함

## 주요 기능

- **캠퍼스 Q&A**: 학교생활 관련 질문에 자연어로 답변
- **공지사항 안내**: 한성대학교 웹 정보를 검색해 최신 공지 안내
- **학사·수강신청 안내**: 일정과 절차 관련 질문 응답
- **입학 안내**: 전형, 일정 등 입학 정보 안내
- **내부 문서 기반 답변**: 관리자가 등록한 문서를 우선 참고
- **웹 검색 보완**: 내부 문서에 정보가 부족하면 DuckDuckGo 검색 결과 활용
- **관리자 기능**: 지식 문서와 사용자 관리, 가입 승인 기능 제공

## 답변 처리 흐름

1. 사용자가 캠퍼스 관련 질문을 입력합니다.
2. 시스템이 관리자가 등록한 내부 문서를 먼저 검색합니다.
3. 필요한 정보가 부족하면 웹 검색으로 관련 내용을 보완합니다.
4. 검색한 정보를 바탕으로 LLM이 자연어 답변을 생성합니다.
5. 답변과 대화 기록을 서비스에서 확인할 수 있도록 제공합니다.

## 기술 구성

| 영역 | 기술 |
|---|---|
| 프론트엔드 | React, TypeScript, Tailwind CSS, Vite |
| API 통신 | tRPC, TanStack Query |
| 백엔드 | Node.js, Express |
| 데이터베이스 | PostgreSQL, Drizzle ORM |
| AI·검색 | LLM API, 내부 문서 검색, DuckDuckGo 검색 |

## 시스템 구조

- **Client**: 사용자 채팅 화면과 관리자 화면 제공
- **Server**: tRPC API와 서비스 로직 처리
- **Database**: 사용자, 대화, 메시지 등 서비스 데이터 저장
- **Knowledge Base**: 관리자가 등록한 문서를 답변 생성에 활용
- **Web Search**: 내부 문서에서 찾지 못한 정보를 보완

## 개발 과정에서 다룬 내용

- 프론트엔드와 백엔드 간 tRPC API 연결
